# DEAD ROAD 404

Videojuego independiente de terror y supervivencia ambientado en la América de 1992.

**Versión en preparación: Fase 19 (v0.19.0).** Proyecto en TypeScript, Three.js y Vite con edición Windows/Linux y futura publicación web.

> El código y los recursos completos de la Fase 19 todavía no se han importado a este repositorio. Este commit inicial solo crea el repositorio y prepara la subida. No es una versión jugable ni una publicación de GitHub Pages.

## Publicar la Fase 19

En tu ordenador, descomprime el ZIP de la Fase 19 y copia **el contenido** de la carpeta `DEAD-ROAD-404` a la raíz de este repositorio. Conserva `.github/workflows/deploy.yml`, `src/`, `public/`, `tests/`, `tools/`, `package.json` y los lanzadores. No subas `node_modules/`, `dist/` ni `.env`.

Tras instalar Git, desde PowerShell puedes iniciar la subida ejecutando el publicador de Windows adjunto a la entrega.
